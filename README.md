# AlfabetoDivertido

Jogo de alfabetização com três modos: letra inicial, montar palavras e explorar o alfabeto.

- [Aplicativo Godot para Android](apps/alfabeto-godot/README.md): tela cheia em paisagem, áudio offline e layout sem rolagem.
- [Versão web](apps/alfabeto-divertido/).

APK de teste: `builds/android/alfabeto-divertido-debug.apk`. Os endereços das ferramentas estão registrados em `AGENTS.md`.
