# Ferramentas locais

Utilize os caminhos abaixo nas tarefas deste projeto que precisarem dessas ferramentas. Os endereços foram informados pelo usuário.

| Ferramenta | Diretório |
| --- | --- |
| Godot | `D:\desenvolvimento\Godot` |
| Blender 5.2 | `D:\desenvolvimento\BlenderFoundation\Blender5_2` |
| Android SDK | `D:\desenvolvimento\ferramentas_android\Sdk` |

Esses caminhos indicam os diretórios de instalação. Localize o executável necessário dentro do diretório correspondente antes de executar a ferramenta.
